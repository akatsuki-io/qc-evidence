# qc-evidence

Screenshots / GIFs proving a QC test case or bug fix. Branch `main` only; one folder per task (bug id, scope id, or lane name), files named `<task>-<nn>-<state>.png`.

Push with `~/.fillr-evidence/push-evidence.sh <task> <file>...` — it prints the raw links to paste into the PR body / sheet dev-note.
